# Prompts maestros por tipo de activo (en inglés, listos para pegar)

Siempre en 9:16 (se elige en el chip de ajustes, no solo en el texto). Sustituir lo que va entre corchetes. Sin marcas, emblemas, logos ni letras de terceros.

## Avatar (retrato maestro)
```
Ultra-realistic vertical portrait photograph, 9:16, waist-up, of [age range] adult [man/woman], [hair], [distinctive but ordinary facial features], wearing [exact clothing: color, fabric, collar, sleeves], [accessories]. Neutral relaxed expression, looking at the camera, soft diffused light, plain warm-grey studio background, shot on a full-frame camera, 85mm lens, natural skin texture. No text, no logos, no brand marks, no jewelry unless listed.
```
Hoja de expresiones (opcional, misma persona):
```
The same person as the attached image, same hair and same clothing, shown in three vertical frames side by side: neutral, restrained surprise (eyebrows up, mouth slightly open), soft smile. Plain warm-grey background, same light. Not exaggerated, not cartoonish.
```

## Fondo / escenario
```
Ultra-realistic vertical photograph, 9:16, of an empty [place: tidy home garage / living room / workshop], [time and light: warm overhead light / soft window light / Christmas lights], [key fixed elements: shelves, workbench, tree], shot on a full-frame camera, 35mm lens, shallow depth of field. No people, no text, no logos.
```

## Producto con texto o números (SOLO TEXTO, sin imagen adjunta)
```
Ultra-realistic vertical product photograph, 9:16, of [product description] on [surface], [light], shot on a full-frame camera, 50mm lens. Piece one: [exact description, colors, materials, printed text in quotes]. Piece two: [structure as a strict grid, exactly N across and exactly M tall, K identical parts, all closed and flush]. Numbers read like a calendar, left to right then top to bottom: [row 1], [row 2], [row 3], [row 4]. The structure is only M rows high, never M+1. Every number appears exactly once. No people, no extra text, no brand logos.
```

## Reemplazar una portada o arte original (edición dirigida)
Subir antes el recorte de la pieza original. Después:
```
Replace only the front cover artwork of [piece] with the cover design from the attached image, reproduced faithfully and filling the whole front: [list each text and image element]. Keep [the rest of the product] exactly as it is. Keep the lighting, the background and the camera angle unchanged.
```

## Quitar marcas y emblemas (edición dirigida, después de revisar a 2K)
```
Remove every badge, emblem, logo and lettering from [the object]: [list the places seen]. Leave those surfaces plain and smooth. Keep everything else identical: the shape, the paint, the lights, the background and the camera angle.
```

## Producto en uso / vehículo en su lugar
```
Ultra-realistic vertical photograph, 9:16, of a full-size real [object description without brand names], [placement], [lighting], [viewpoint]. [Exact distinctive features: headlights, vents, wheels, colors]. Clean, with soft reflections. No badges, no emblems, no brand logos, no license plate text, no people, no extra text.
```

## Macro de detalle (recurso DETALLE)
```
Ultra-realistic vertical macro photograph, 9:16, close-up of [detail: gold foil numbers on matte burgundy drawers / red brake caliper behind a black wheel / hand pulling a drawer], shallow depth of field, [light]. Keep the colors and materials exactly as in the attached image. No extra text.
```

## Video por tomas con varias referencias (Ingredientes)
```
Fast-paced multi-shot sequence, vertical 9:16, energetic handheld phone footage, quick cuts every 1 to 1.5 seconds like a movie trailer, whip pans and punch-ins, warm mixed lighting, slight grain. References: the first image is [avatar and place], the second image is [product], the third image is [prop or vehicle]. Shot 1 (0-1.3s): … Shot 2 (1.3-2.6s): … Shot 3 (2.6-3.9s): … Keep [objects] exactly as in the references: no badges, no logos. No speech, no music, only [ambient sounds].
```

## Video continuo desde un fotograma (Fotogramas)
```
Continue seamlessly from the first frame: same [person], same [place], same [objects], same handheld phone footage with natural sway. Keep both the [person] and the [object] in frame at all times and keep the framing stable, no tilting up to the ceiling. [One clear action]. No badges, no logos, no text. Only [one or two ambient sounds], no speech, no music.
```
