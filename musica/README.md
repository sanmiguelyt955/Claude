# Biblioteca musical (skill musica-para-video)

Lo guarda todo la herramienta; no hace falta editar a mano.

- `biblioteca.json`: ficha de cada canción (BPM, pulsos, tonalidad, energía, clímax, voces, ánimo, género).
- `emb/`: huellas de sonido (CLAP) de cada canción y de los ejemplos (`ej_*.npz`, con su huella visual CLIP).
- `canciones/`: los archivos de audio, para poder montarlos en los videos.
- `gustos.json`: tus 👍/👎.
- `ejemplos.json`: videos tuyos o virales que sirven de referencia.

Las canciones comerciales son tuyas para uso personal: el repo es privado; no lo hagas público con ellas dentro.
